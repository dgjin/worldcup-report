# 冠军照片署名字号设计

## 目标

降低“摄影/来源：Juan Mabromata/AFP via Getty Images”的视觉权重，让冠军照片、标题和比分继续占据主要层级。

## 设计

- 仅将冠军照片摄影来源链接的字号从 16px 调整为固定 12px。
- 保留现有 `min-h-11`，使链接触控区域高度继续保持至少 44px。
- 不修改链接颜色、悬停下划线、摄影者文字、原文地址、加载成功后显示条件或移动端换行行为。
- 不缩小冠军标题、决赛比分、队名、进球者和同步提示。

## 验证

- 更新 `ChampionMoment` 源代码契约测试，明确摄影来源链接包含 `text-xs` 与 `min-h-11`。
- 将原有“小字号不得出现”断言收窄到 `text-[10px]` 和 `text-sm`，允许经设计批准的摄影署名使用 `text-xs`。
- 运行冠军组件测试、375px 移动端回归、完整测试和生产构建。

## 验收标准

1. 摄影来源文字以 12px 显示。
2. 链接触控区域高度不低于 44px。
3. 冠军模块其他正文仍保持至少 16px。
4. 深浅主题、外链行为和图片加载逻辑不变。
