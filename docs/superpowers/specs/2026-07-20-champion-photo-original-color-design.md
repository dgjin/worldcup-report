# 冠军照片原色强化设计

## 目标

将“夺冠时刻”从红金氛围主导调整为照片主导。Rodri、世界杯奖杯和西班牙队员应成为第一视觉焦点，同时维持标题、比分和摄影署名的可读性。

## 已选方向

采用视觉对比中的 A「照片主导」方案：完整保留照片原始色彩与主体细节，仅用局部压暗帮助文字阅读。现有组件结构、内容顺序、图片来源和加载失败回退逻辑保持不变。

## 图片处理

- 移除照片的 `mix-blend-mode: luminosity`，避免原色被红色背景重新着色。
- 移除降饱和滤镜；不人为增强色相，保持来源图片的自然色彩。
- 将照片提升至接近全不透明，使其成为完整的全幅主视觉。
- 移除移动端纵向渐隐和桌面端横向渐隐遮罩，避免人物、队员或球场环境被裁成背景纹理。
- 保留现有响应式 `object-position`，保证 375px 与桌面宽度下 Rodri 和奖杯均位于主要可视区域。

## 前景与装饰

- 暗角只压低四周及底部，不改变主体区域色相；底部压暗用于承托比分和署名。
- 保留红金边框、皇冠、奖杯图标、放射线、飘带和微粒，以延续冠军仪式感。
- 降低放射线与飘带的不透明度，避免跨越人物和奖杯时形成视觉遮挡。
- 深色与浅色主题使用相同照片色彩处理；主题差异只体现在边框、文字衬底与暗角强度。
- 保留现有减少动态效果行为，不增加新动画。

## 组件和数据边界

- 仅调整 `src/index.css` 中冠军模块的图片、暗角和装饰样式。
- 不修改 `ChampionMoment` 的数据选择、决赛比分、图片回退、加载状态或来源链接逻辑。
- 不修改图库、积分榜、导航和其他页面。

## 验证

- 增加源代码样式契约断言，确保照片不再使用 `luminosity`、降饱和或渐隐遮罩。
- 运行冠军模块测试、375px 移动端布局回归、完整测试和生产构建。
- 验证深浅主题均无横向溢出，标题与比分可读，图片失败时红金背景仍能完整兜底。

## 验收标准

1. 照片以原色呈现，Rodri、奖杯和队员明显比红金装饰更突出。
2. 照片覆盖整个冠军区域，不再在下方或左侧渐隐为红色背景。
3. 标题、比分和署名在深浅主题下均清晰可读。
4. 装饰仍保留冠军氛围，但不遮挡主题人物和奖杯。
5. 375px 移动端无横向溢出，图片加载失败回退不受影响。
