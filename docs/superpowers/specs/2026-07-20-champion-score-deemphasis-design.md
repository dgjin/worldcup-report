# 冠军比分区域中度淡化设计

## 目标

移除“进球信息同步中”提示，并降低决赛比分区域的视觉权重，让原色冠军照片和“西班牙”标题保持第一视觉层级。

## 内容行为

- 完全移除“进球信息同步中”文案以及 `ChampionMoment` 内为该文案执行的完整性判断。
- 已同步的进球者、分钟、点球和乌龙标记继续正常显示；不因进球事件不完整而隐藏已有数据。
- 保留“比分同步中”，因为它只在决赛核心比分缺失时出现，与进球明细完整性无关。
- 保留无决赛数据时的“决赛战报同步中”。
- 不修改 `hasIncompleteGoalEvents` 库函数及其独立测试，避免扩大到其他潜在调用者。

## 中度淡化样式

- 比分卡背景从 `bg-black/30` 降为 `bg-black/15`。
- 边框从 `border-white/15` 降为 `border-white/10`。
- 移除 `shadow-2xl`，将 `backdrop-blur-md` 降为 `backdrop-blur-sm`。
- 队名从 `text-white` 降为 `text-white/80`。
- 主比分从 `text-white` 降为 `text-white/85`。
- 进球者信息从 `text-white/65` 降为 `text-white/55`。
- 金色分钟、点球标记、乌龙标记和国旗保持现状，确保关键信息仍可辨认。

## 组件边界

- 仅修改 `src/views/ChampionMoment.tsx` 与对应测试。
- 不修改冠军照片、标题、摄影署名、图片加载回退、比赛筛选、图库或其他页面。
- 不新增 CSS 文件、组件或依赖。

## 验证

- 更新源代码契约测试，确认组件不再包含“进球信息同步中”或调用 `hasIncompleteGoalEvents`。
- 更新服务端渲染断言，确认进球明细为空、缺失或部分同步时均不显示该文案。
- 保留已有进球渲染、0–0 比分和比分缺失兜底测试。
- 运行冠军组件测试、375px 移动端回归、完整测试和生产构建。

## 验收标准

1. 页面任何状态下都不显示“进球信息同步中”。
2. 已有进球明细继续显示，不完整数据不产生额外提示。
3. 比分卡的背景、边框、阴影、模糊和文字亮度均按中度方案降低。
4. “比分同步中”和“决赛战报同步中”继续按原条件工作。
5. 375px 移动端无横向溢出，深浅主题信息仍可辨认。
