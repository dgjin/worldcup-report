# 西班牙夺冠时刻设计说明

## 目标

将积分榜页顶部的“今日速递”完全替换为“夺冠时刻”：以写意、具有仪式感的方式庆祝西班牙夺得 2026 世界杯冠军，同时保留决赛比分和进球信息，使其仍然符合“世界杯战报”产品定位。

## 视觉方向：红色加冕

- 延续站点现有深色赛事仪表盘基底，以西班牙红、深红和冠军金作为局部主色。
- 默认用纯 CSS 构成斜向红色飘带、金色日轮/放射线、微粒和抽象国旗笔触；当图集出现高置信度的西班牙颁奖照片时，自动将其融入主视觉。
- 主视觉层级依次为：`夺冠时刻`、奖杯与皇冠、`西班牙`、`CAMPEONES`、四颗冠军星。
- 照片模式下，影像作为右侧/底层的全幅画面，覆盖深红渐变与轻微颗粒；标题、奖杯、四星和写意飘带仍位于前景，保证品牌表达和文字可读性。
- 海报采用移动端优先布局；桌面端增加横向层次和留白，但不改变信息顺序。
- 浅色主题使用更深的西班牙红和较克制的金色，保证文字与装饰层的对比度。

## 内容与数据

- 固定庆祝文案为“冠军属于西班牙”，英文点题使用“CAMPEONES”。
- 在现有赛事数据中查找最新一场包含西班牙的已完赛决赛，显示双方国旗、中文队名、常规/加时赛最终比分及进球者。
- 不写死或猜测决赛比分。找不到符合条件的比赛时，比分带显示“决赛战报同步中”。
- 复用现有图集接口获取候选照片，不增加新的图片服务或接口密钥。
- 自动选图必须同时命中西班牙语义（`Spain`、`Spanish` 或“西班牙”）和夺冠/颁奖语义（`champion`、`trophy`、`lift`、`crown`、“冠军”、“捧杯”或“颁奖”）。横向构图和更新较新的照片只作为同等语义置信度下的排序加分项，不能替代双重语义命中。
- 只采用达到双重语义阈值的最高分照片。说明仅为“世界杯精彩瞬间”等通用内容的图片不得入选。
- 照片模式显示摄影者或媒体署名，并链接图片记录中的原始报道地址。
- 移除原“今日速递”的比赛日统计、回退提示和比赛列表，不影响页面下方球迷交流、积分榜及访问量。

## 组件边界

- 将原 `TodayBriefing` 改造为职责单一的冠军时刻区域。
- 保留并复用现有 `Flag`、`GoalStrip`、球队中文名及赛事类型，不重复建立球队或比分模型。
- 新增小型内部展示组件时，仅负责奖杯主视觉、冠军星和决赛比分带，数据筛选集中在冠军区域入口。
- 自动照片选择实现为独立纯函数，输入图集照片列表，输出最高置信度照片或 `null`，便于独立测试和调整阈值。
- 冠军区域调用现有图集读取能力，但不触发刷新、不改变图集页面状态，也不参与点赞逻辑。

## 动效与可访问性

- 首次出现时执行一次文字揭幕、飘带舒展和金色微粒上浮；不循环制造视觉干扰。
- 使用 `motion/react` 与 CSS 动画实现，不增加依赖。
- `prefers-reduced-motion: reduce` 下关闭装饰动画并直接展示最终状态。
- 装饰图形标记为非语义内容；关键信息保持真实文字，移动端正文不低于 16px，颜色满足可读性要求。
- 照片使用有意义的替代文本；照片加载失败时隐藏破损影像并恢复完整的纯 CSS 红金背景。

## 验收标准

1. 积分榜页不再出现“今日速递”或“最新战况”，顶部标题显示“夺冠时刻”。
2. 首屏明确表达西班牙夺冠，并呈现红金写意加冕视觉。
3. 有决赛数据时展示真实对阵、比分与进球者；无数据时展示同步提示。
4. 图集出现同时明确指向西班牙与夺冠/颁奖的图片时，自动展示最高分照片、来源署名和原文链接。
5. 无高置信度候选或照片加载失败时，完整展示红金写意兜底，不出现空白或破图。
6. 375px 移动端无横向滚动，桌面端视觉层级完整。
7. 深浅主题均清晰可读，减少动态效果设置生效。
8. 自动选图纯函数覆盖双重语义阈值、排序和无候选测试；TypeScript 检查、现有测试和生产构建全部通过。

## 非目标

- 不修改其他页面导航、积分榜、球迷交流或数据接口。
- 不新增音频、视频、图片下载、外部图像识别服务或全站庆祝效果。
- 不虚构比赛比分、球员或比赛时间。
